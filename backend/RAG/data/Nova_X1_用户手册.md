## Nova 耳机 X1 用户使用手册

### 1. 产品基础信息

生产公司：星河科技有限公司 产品名称：Nova 耳机 X1 无线主动降噪蓝牙耳机 产品类型：TWS双耳无线蓝牙耳机 蓝牙版本：Bluetooth 5.3 电池参数：耳机单耳45mAh，充电仓450mAh 续航时长：单次续航6小时，综合续航28小时 防水等级：IPX4生活防汗防水 适配系统：安卓 8.0及以上、iOS 13.0及以上、Windows10/11、macOS 包装清单：左耳耳机、右耳耳机、充电仓、Type-C充电线、硅胶耳塞（S/M/L三尺寸）、纸质说明书、保修卡。

### 2. 开机与关机操作详解

- **自动开机**：将耳机从充电仓取出，耳机金属触点断开充电感应，设备自动上电开机，白色指示灯常亮2秒，完成开机自检流程，自检无异常后进入待配对状态。
- **自动关机**：将耳机平稳放回充电仓，确保耳机金属触点与仓内弹片贴合，闭合仓盖后耳机自动断电关机并进入补电状态。
- **手动强制关机**：耳机任意工作状态下，长按单侧耳机触控区域5秒，指示灯快速闪烁两次，设备强制断电关机，适用于系统卡顿、无响应场景。
- **待机休眠机制**：耳机成功连接播放设备后，无音乐播放、无通话、无触控操作静置10分钟，自动进入低功耗休眠模式，降低电量消耗；休眠后触碰触控区可快速唤醒设备。

### 3. 指示灯状态完整说明

本产品耳机机身内置高通透隐藏式LED指示灯，不同灯光颜色、闪烁频次对应设备不同运行状态，为方便用户快速排查设备状态，全部灯光逻辑统一说明如下：

- 白灯常亮2秒：开机自检完成、设备正常待机
- 白灯慢速间隔闪烁：蓝牙配对中，等待外部设备连接
- 蓝灯常亮：已成功连接播放设备，处于正常工作状态
- **红灯连续闪烁三下：耳机电池低压告警，剩余电量不足10%，请及时放入充电仓充电，避免设备自动断电关机**
- 红灯长亮：耳机正在充电中；红灯自动熄灭：单耳电量充满
- 红白交替快速闪烁：系统程序异常、配对紊乱，需进行设备重置
- 蓝灯快速双闪：通话接入、来电提醒状态
- 白灯快速频闪：固件升级进行中，禁止断开电源

### 4. 设备重置详细教程（通用故障修复）

当出现蓝牙连接失败、单耳断连、声音延迟、触控失灵、配对记录混乱等问题时，可执行设备重置，清除全部历史配对数据，恢复出厂默认设置。重置不会损坏设备硬件，为官方推荐故障修复方式。

1. 将两只耳机同时取出充电仓，确保耳机处于开机非休眠状态；
2. 同时长按左右耳机触控区域8秒，观察指示灯变为红白交替闪烁；
3. 松开手指，保持耳机静置，等待指示灯自动熄灭，重置流程完成；
4. 重置后耳机清除所有手机、电脑蓝牙配对记录，两台耳机自动完成双耳互联，需重新与播放设备配对连接。

### 5. 充电规范与安全注意事项

- 本产品充电额定输入规格为5V/1A及以下，严格禁止使用20W、40W、65W大功率快充头，过压过流会损伤电池保护板。
- 充电前务必保持充电仓接口、耳机金属触点干燥清洁，避免积水、汗液、灰尘堆积造成短路、接触不良。
- 单次满电充电时长不超过1.5小时，电池充满后及时断开电源，长期过充会加速电池老化。
- 禁止在高温、潮湿、密闭闷热环境下充电，环境温度建议保持在5℃-35℃之间。
- 长期不使用耳机，建议每30天补充一次电量，防止电池过度亏电导致永久性损坏。

### 6. 触控操作手势说明

- 单击任意耳机触控区：播放/暂停音乐、接听来电
- 双击右耳机触控区：切换下一首歌曲
- 双击左耳机触控区：切换上一首歌曲
- 三击触控区：唤醒手机自带智能语音助手
- 长按2秒：拒接来电、手动开启降噪模式
